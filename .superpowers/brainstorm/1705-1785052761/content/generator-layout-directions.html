C. Guided wizard

The clearest learning path for beginners and small screens. It explains each choice, but experienced users must move through several steps.

My recommendation

  • Use A as the working interface.
  • Add a compact template picker from B inside the task control.
  • Keep every selected combination valid—no dead-end error states.

Responsive rule

  • Desktop: sticky controls + wide output.
  • Tablet: balanced two-column layout.
  • Mobile: one column, full-width controls, horizontally scrollable code.
